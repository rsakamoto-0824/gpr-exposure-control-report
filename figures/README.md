# 図ファイル

すべての図は外部画像として後から配置します。
以下のファイル名と一致する画像をこのディレクトリに置いてください。
未配置の場合はPDF内にプレースホルダーが表示されます。

PNG、PDF、JPG、JPEGのいずれかを使用できます。
例えば `layer_stack.png` または `layer_stack.pdf` を配置すると、本文の変更なしで自動的に読み込まれます。
